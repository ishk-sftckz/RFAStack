# Runnable examples

Choose an application by the problem you want to study. These projects have different requirements and independent installations.

| Application | Strategy | Start here |
| --- | --- | --- |
| Customer order portal | Native Next.js queries and Server Actions | [Setup and walkthrough](./next-native/README.md) |
| Fulfillment dashboard | React Query with a separate HTTP backend | [Setup and walkthrough](./react-query-http/README.md) |
| B2B ordering | React Query and oRPC, with a typed CLI consumer | [Setup and walkthrough](./react-query-orpc/README.md) |

Each uses PostgreSQL, Drizzle, Better Auth, and Cache Components. Their source is deliberately independent so you can follow a complete application's feature boundaries without opening another example. There is no workspace installation at this level.
